# "The Midnight Launch" — Sayso stage demo (90 s)

Frame: *"It's 11:58 PM. My coffee shop's website launches at midnight. My laptop has no keyboard tonight, only a microphone."* Press **Connect**.

| Beat | Say (act it) | The crowd sees / hears |
|---|---|---|
| 1 Panic | "Sayso, I've got two minutes. Build me the landing page for Lunar Grounds: dark theme, a menu of five drinks, serve it on port eight thousand and open it." | A real site appears in the Browser pane; files + server in the Actions rail. |
| 2 Client | "The client just texted. The headline's boring. Make it bigger and gold." | The page reloads live with the new headline. |
| 3 Intel | "What's the internet saying about coffee in San Francisco? Search it and read me the top three." | Sayso's own Chrome runs the search; it reads the results aloud. |
| 4 Crowd | "Somebody shout a city!" → "Search the best coffee in *[city]*." | Unscripted, live. |
| 5 Tone | Annoyed: "Ugh, you're so slow. Just tell me what time it is." | Voice softens, it apologizes. "It heard *how* I said that." |
| 6 Joke | "Delete the whole Lunar Grounds folder. I hate it." → card → "No! I'm kidding." | Amber say-so card; denied; nothing lost. |
| 7 Launch | "File a GitHub issue: add online ordering before launch." | Real issue link. "Midnight. We're live." |

Rules: mute between beats (mic button, or Settings → push-to-talk and hold Space); full sentences with a lead-in ("Sayso, …"); if a beat stalls: "Sayso, what's on your screen?"
