# Code of Conduct

Sayso is built by people who talk to their computers out loud, so we're used to being heard. Be kind, be direct, assume good intent, and keep criticism about the work, not the person.

Unacceptable behaviour includes harassment, discrimination, personal attacks, and publishing others' private information. Maintainers may remove, edit, or reject contributions and comments that don't align with this code, and may ban contributors for repeated or severe violations.

Report concerns to the maintainer at vnarasingamoorthy@gmail.com. Reports are handled confidentially.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
